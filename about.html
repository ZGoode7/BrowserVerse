About Me

Welcome to the About Me page of BrowserVerse. This page introduces the creator of the website and explains the purpose of the project.

About the Creator

My name is Z Goode, and I am a student at Kennesaw State University majoring in Information Technology. I've created BrowserVerse as part of my IT 3203 Introduction to Web Development course.

About BrowserVerse

BrowserVerse is a website made and created to explore the history, technology, and development of web browsers. The project covers how browsers have evolved, the technologies behind them, and important concepts related to web development as a whole.

Class Project Information

BrowserVerse was created as a class project for IT 3203 at Kennesaw State University. Visit the IT 3203 course website for more information.
